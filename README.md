# TradeCore ERP

TradeCore is a professional, multi-industry business management platform (ERP) built with Vanilla TypeScript and Tailwind CSS. 

## 🚀 Features

- **Multi-Industry Support**: Switch between Pharmacy, Grocery, and Retail modes.
- **Inventory Management**: Full CRUD for products, SKU generation, and low-stock alerts.
- **Sales & POS**: Dynamic cart system, checkout, and inventory deduction.
- **Procurement**: Supplier management and purchase order tracking.
- **CRM**: Customer management with balance tracking.
- **Accounting & Finance**: Real-time income/expense ledger and profit calculation.
- **Reports & Analytics**: Sales trends, inventory health, and financial summaries.
- **Global Search**: Instant search across products, customers, and invoices.
- **Alerts System**: Real-time notifications for low stock, expiring products, and due payments.

## 🛠️ Tech Stack

- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Icons**: Lucide React (SVG)
